# Dotfiles

Personal config for macOS and Linux. Managed with Nix (nix-darwin + home-manager).

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/yu-sz/dotfiles/main/scripts/bootstrap.sh | bash
```

### Post-install (manual)

- Configure Raycast manually (see [docs/raycast.md](docs/raycast.md))

## AI Agents

Claude Code / Codex CLI / Gemini CLI are managed declaratively:

- Packages come from [llm-agents.nix](https://github.com/numtide/llm-agents.nix) (binary cache: cache.numtide.com), updated weekly by the flake.lock workflow
- `config/agents/` is the single source of truth for shared instructions (AGENTS.md) and skills
- MCP servers are defined once in `nix/home/agents/mcp-servers.nix` and distributed to all three agents
- Mutable files (`settings.json` / `config.toml`) are generated by `agents-sync` (base ⊕ MCP ⊕ `*.local.*` deep merge)
- On a new machine, run `just agents-plugins` once to install Claude Code plugins declared in `settings.json`
